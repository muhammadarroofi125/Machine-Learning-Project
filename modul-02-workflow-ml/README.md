# Modul 2 --- Workflow Machine Learning

## Deskripsi

Folder ini berisi latihan praktikum Modul 2 mengenai alur kerja
pengembangan model Machine Learning, mulai dari memahami masalah hingga
mengevaluasi hasil model.

## Materi Praktikum

-   Alur kerja (workflow) Machine Learning.
-   Tahapan CRISP-DM.
-   Pembagian data untuk pelatihan dan evaluasi.
-   Konsep bias dan variance.
-   Underfitting dan overfitting.
-   Pemilihan model berdasarkan hasil validasi.

## File Praktikum

Simpan notebook .ipynb, script .py, dataset, dan dokumentasi hasil
praktikum di folder ini.

## Tools

-   Python
-   Google Colab
-   Library pengolahan data dan Machine Learning sesuai latihan

## Cara Menjalankan

1.  Buka notebook menggunakan Google Colab.
2.  Siapkan dataset dan jalankan tahapan sesuai urutan praktikum.
3.  Perhatikan pembagian data serta proses pelatihan dan validasi.
4.  Catat hasil dan kesimpulan pada notebook.

## Hasil Praktikum

Dokumentasi proses dan hasil pengerjaan tersedia pada file praktikum di
folder ini.
