# Modul 4 --- Feature Engineering dan Pipeline

## Deskripsi

Folder ini berisi latihan praktikum Modul 4 mengenai pengolahan dan
pembentukan fitur agar data lebih siap digunakan oleh model Machine
Learning.

## Materi Praktikum

-   Konsep feature engineering.
-   Seleksi fitur, termasuk pengujian Chi-Square.
-   Transformasi fitur numerik.
-   Encoding fitur kategorikal: nominal dan ordinal.
-   Imputasi nilai yang hilang.
-   Scaling atau standardisasi fitur.
-   Pembentukan fitur baru (feature construction).
-   Penyusunan pipeline preprocessing dan penggunaan ColumnTransformer.
-   Pencegahan data leakage.

## File Praktikum

Simpan notebook .ipynb, dataset pendukung, script Python, dan
dokumentasi hasil di folder ini.

## Tools

-   Python
-   Google Colab
-   pandas dan NumPy
-   scikit-learn

## Cara Menjalankan

1.  Buka notebook menggunakan Google Colab.
2.  Siapkan dataset yang digunakan.
3.  Identifikasi jenis setiap fitur.
4.  Jalankan preprocessing dan pipeline sesuai urutan latihan.
5.  Periksa hasil transformasi fitur dan dokumentasikan kesimpulannya.

## Hasil Praktikum

Hasil seleksi fitur, transformasi, dan preprocessing dicantumkan pada
notebook.
