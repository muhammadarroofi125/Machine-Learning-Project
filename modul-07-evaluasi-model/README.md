# Modul 7 --- Evaluasi Model Klasifikasi

## Deskripsi

Folder ini berisi latihan praktikum Modul 7 mengenai evaluasi performa
model klasifikasi. Evaluasi digunakan untuk memahami ketepatan prediksi
serta jenis kesalahan yang dihasilkan model.

## Materi Praktikum

-   Pembagian data train, validation, dan test.
-   Confusion Matrix: True Positive (TP), True Negative (TN), False
    Positive (FP), dan False Negative (FN).
-   Accuracy, Precision, Recall, dan F1-Score.
-   F-beta untuk memberikan bobot berbeda pada precision dan recall.
-   Pengaruh ketidakseimbangan kelas terhadap accuracy.
-   Pemilihan threshold.
-   ROC Curve dan ROC-AUC.
-   Precision-Recall Curve dan PR-AUC.
-   Macro, Micro, dan Weighted averaging.
-   Stratified K-Fold Cross-Validation.
-   Evaluasi akhir menggunakan data test.

## File Praktikum

Simpan notebook .ipynb, script Python, dataset, grafik, dan hasil
praktikum di folder ini.

## Tools

-   Python
-   Google Colab
-   pandas dan NumPy
-   scikit-learn
-   Matplotlib atau library visualisasi sesuai kebutuhan

## Cara Menjalankan

1.  Buka notebook di Google Colab.
2.  Siapkan dataset dan model yang akan dievaluasi.
3.  Jalankan proses evaluasi sesuai urutan praktikum.
4.  Periksa confusion matrix, metrik, dan kurva evaluasi.
5.  Tuliskan interpretasi hasil serta kesimpulan.

## Hasil Praktikum

Metrik evaluasi, visualisasi, dan pembahasan hasil model dicantumkan
pada notebook.
