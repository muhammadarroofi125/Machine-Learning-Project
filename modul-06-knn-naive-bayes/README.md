# Modul 6 --- KNN dan Naive Bayes

## Deskripsi

Folder ini berisi latihan praktikum Modul 6 mengenai dua algoritma
klasifikasi, yaitu K-Nearest Neighbors (KNN) dan Naive Bayes.

## Materi Praktikum

-   Konsep dan alur prediksi KNN.
-   Pemilihan nilai k dan majority voting.
-   Perhitungan jarak Euclidean, Manhattan, dan Minkowski.
-   Standardisasi atau scaling fitur.
-   Weighted KNN.
-   Konsep probabilitas pada Naive Bayes.
-   Prior, likelihood, dan posterior.
-   Asumsi independensi bersyarat (naive assumption).
-   Gaussian, Multinomial, dan Bernoulli Naive Bayes.
-   Laplace smoothing.

## File Praktikum

Simpan notebook .ipynb, script Python, dataset, dan hasil praktikum di
folder ini.

## Tools

-   Python
-   Google Colab
-   pandas dan NumPy
-   scikit-learn

## Cara Menjalankan

1.  Buka notebook menggunakan Google Colab.
2.  Siapkan dataset sesuai latihan.
3.  Jalankan preprocessing dan perhitungan atau pelatihan model.
4.  Periksa hasil prediksi dan evaluasi.
5.  Tuliskan kesimpulan berdasarkan hasil praktikum.

## Hasil Praktikum

Hasil perhitungan jarak, prediksi KNN, atau probabilitas Naive Bayes
dicantumkan pada notebook sesuai latihan.
