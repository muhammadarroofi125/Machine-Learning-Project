# Modul 5 --- Decision Tree (CART, ID3, dan Pruning)

## Deskripsi

Folder ini berisi latihan praktikum Modul 5 tentang algoritma Decision
Tree. Materi membahas struktur pohon keputusan, pengukuran kualitas
pemisahan data, serta pengendalian kompleksitas pohon.

## Materi Praktikum

-   Struktur Decision Tree: root node, internal node, branch, dan leaf.
-   Proses pembentukan pohon secara rekursif.
-   Perhitungan Gini dan Entropy.
-   Information Gain.
-   Perbandingan CART dan ID3.
-   Interpretasi hasil model Decision Tree.
-   Pre-pruning dan post-pruning.
-   Cost-complexity pruning.
-   Evaluasi kedalaman pohon untuk mengendalikan overfitting dan
    underfitting.

## File Praktikum

Simpan notebook .ipynb, script Python, dataset, dan hasil praktikum di
folder ini.

## Tools

-   Python
-   Google Colab
-   pandas
-   scikit-learn
-   Library pendukung visualisasi jika diperlukan

## Cara Menjalankan

1.  Buka notebook di Google Colab.
2.  Siapkan dataset dan jalankan kode sesuai urutan.
3.  Periksa perhitungan atau hasil pembentukan pohon.
4.  Evaluasi model menggunakan data validasi sesuai latihan.
5.  Tuliskan interpretasi dan kesimpulan.

## Hasil Praktikum

Hasil perhitungan, model, evaluasi, dan kesimpulan tersedia pada
