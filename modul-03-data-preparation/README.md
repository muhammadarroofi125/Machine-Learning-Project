# Modul 3 --- Data Preparation Lanjutan

## Deskripsi

Folder ini berisi latihan praktikum Modul 3 mengenai persiapan data
sebelum digunakan untuk membangun model Machine Learning.

## Materi Praktikum

-   Penanganan nilai yang hilang (missing values).
-   Imputasi menggunakan mean dan median.
-   Identifikasi dan penanganan outlier.
-   Deteksi outlier menggunakan metode IQR dan Z-Score.
-   Penanganan data tidak seimbang (imbalanced data).
-   Class weighting.
-   Pembentukan data sintetis menggunakan SMOTE.
-   Pencegahan data leakage saat persiapan data.

## File Praktikum

Simpan notebook .ipynb, dataset pendukung, script Python, dan hasil
praktikum di folder ini.

## Tools

-   Python
-   Google Colab
-   pandas dan NumPy
-   scikit-learn atau library lain sesuai instruksi praktikum

## Cara Menjalankan

1.  Buka notebook di Google Colab.
2.  Siapkan dataset sesuai latihan.
3.  Jalankan proses pemeriksaan dan persiapan data secara berurutan.
4.  Periksa hasil imputasi, deteksi outlier, atau penanganan
    ketidakseimbangan kelas.
5.  Tuliskan kesimpulan berdasarkan hasil praktikum.

## Hasil Praktikum

Hasil pengolahan data dan pembahasan dicantumkan pada notebook.
