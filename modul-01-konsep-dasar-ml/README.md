# Modul 1 --- Konsep Dasar Machine Learning

## Deskripsi

Folder ini berisi latihan praktikum Modul 1 mengenai konsep dasar
Machine Learning, yaitu proses pembelajaran mesin dari data untuk
mengenali pola dan menghasilkan prediksi atau keputusan.

## Materi Praktikum

-   Pengertian dan konsep dasar Machine Learning.
-   Supervised learning dan unsupervised learning.
-   Klasifikasi dan regresi.
-   Data, fitur (feature), dan target (label).
-   Contoh penerapan Machine Learning.

## File Praktikum

Simpan notebook Google Colab (.ipynb), script Python (.py), dataset
pendukung, dan hasil praktikum yang diwajibkan dosen di folder ini.

## Tools

-   Python
-   Google Colab
-   Library Python sesuai kebutuhan latihan

## Cara Menjalankan

1.  Buka notebook .ipynb menggunakan Google Colab atau Jupyter Notebook.
2.  Siapkan dataset yang digunakan.
3.  Jalankan sel kode secara berurutan.
4.  Periksa hasil eksekusi dan kesimpulan praktikum.

## Hasil Praktikum

Hasil dan kesimpulan dicantumkan pada notebook sesuai instruksi modul
dan dosen.
